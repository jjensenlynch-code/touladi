# Touladi — Carnet de pêche du Québec

App mobile hors ligne, en français, privée et en achat unique.

## [Ouvrir la maquette interactive](https://jjensenlynch-code.github.io/touladi/docs/)

**Lien à partager :** https://jjensenlynch-code.github.io/touladi/docs/

> **Vos données restent à vous.** Dans l'app, vos coordonnées GPS, vos spots et toutes les informations compilées (prises, équipement, dépenses, entretiens) sont privées et restent sur votre téléphone. Aucun compte, aucun serveur. Rien ne quitte l'appareil sans votre action, par exemple un export de sauvegarde que vous choisissez de partager. Pour la météo automatique, seule une position arrondie (≈ 10 km) est envoyée aux services météo, jamais vos spots.

### À propos de la maquette
- Toutes les données sont fictives et rien n'est enregistré.
- Page statique : `docs/index.html`, `docs/runtime.js` (petit moteur de rendu du gabarit), React 18.3.1 dans `docs/vendor/`.
- Photos d'exemple : iNaturalist, sous licence CC BY — Quinn (doré jaune, achigan, perchaude), Lythronax246 (touladi), Daughter Dad (grand brochet).
