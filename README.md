# Touladi — Carnet de pêche du Québec

App mobile hors ligne, en français, privée et en achat unique.

## Maquette interactive
La maquette à faire tester par des pêcheurs se trouve dans `docs/` et est publiée avec GitHub Pages :
https://jjensenlynch-code.github.io/touladi/

- Toutes les données sont fictives et rien n'est enregistré.
- Page statique : `docs/index.html`, `docs/runtime.js` (petit moteur de rendu du gabarit), React 18.3.1 dans `docs/vendor/`.
- Photos d'exemple : iNaturalist, sous licence CC BY — Quinn (doré jaune, achigan, perchaude), Lythronax246 (touladi), Daughter Dad (grand brochet).
